▮ Case 01 · migration
2026 · Analyst

Moving a 26-operation SOAP platform to Spring Boot without breaking a single client

A legacy Group Benefits SOAP service built with WebLogic Ant tooling, moved onto an embedded Spring Boot 4 and Apache CXF JAR on Java 21.

0contract changes for existing clients
How it went
Problem
Existing clients had generated stubs from the published WSDL. Any change to names, types or element order would break them.
What I did
Migrated the build from Ant to Maven, moved javax to jakarta, and rebuilt the service on CXF across three Oracle UCP datasources.
How I proved it
Compared the SHA-256 of the old and new WSDL. Byte-for-byte identical.

▮ Case 02 · AWS
2026 · Analyst

Retiring IBM MQ for an event-driven publishing service on AWS

Rebuilt a Group Benefits event and acknowledgement API on Spring Boot and Java 21, and provisioned its runtime in Terraform.

25 minretry window before a message reaches the DLQ
How it went
Problem
Outbound dispatch ran on IBM MQ with a scheduled batch bootstrap. Failed messages had no clean retry or parking path.
What I did
Provisioned API Gateway, VPC Link, an internal ALB and ECS Fargate in Terraform, with SQS FIFO queues and a 5-attempt redrive to a 14-day dead letter queue. Large payloads go to S3 using the claim-check pattern.
Design choice
Manual acknowledgement: a message is deleted only after the database commit, so a crash causes a retry, not a lost event.

▮ Case 04 · performance
2025 · Associate

A business-critical flow timing out after 3 minutes

A slow endpoint was tripping production gateway timeouts. I traced it through the UI, experience and domain layers down to the query.

70%faster, from 3+ minutes to under 60 seconds
How it went
Symptom
Gateway timeouts on one flow, reproducible with a specific filter. Result sets of 15k rows in test and 25k+ in pre-production.
Isolating it
HAR traces to find the slow call, then timing each hop to separate transport cost from database cost.
Fix
Paged data retrieval with indexed lookups, so the query returns a bounded page instead of the whole result set.
